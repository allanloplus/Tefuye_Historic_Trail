# 跟著 Allan 走特富野古道

由導遊 Allan 帶路的「特富野古道」互動導覽網站：古道知識、交通路線動畫、古道健行場景和小遊戲。純靜態網頁（HTML / CSS / JavaScript），不需要建置工具。

## 內容

| 區塊 | 說明 |
|---|---|
| 古道檔案 | 全長、海拔、時間、入山申請，以及 2026 年最新開放狀態提醒 |
| 四大面向 | 歷史、旅遊、環境、人文，各由 Allan 以不同表情講解 |
| 怎麼去 | 選出發城市（嘉義／台北／台中／高雄）＋交通方式（開車、公車、阿里山火車、機車、自行車），Allan 在示意地圖上一站一站陪你到自忠登山口 |
| 一起走 | 自忠 0K → 特富野端 6.32K 的橫向捲動森林場景，9 個解說站、海拔剖面、發現卡收集 |
| 遊戲場 | 古道知識王（問答）、枕木跳跳（跑酷，撿垃圾加分）、森林偵探（找動物）、行前背包（裝備判斷） |
| 古道護照 | 完成任務蓋章，紀錄只存在瀏覽器 localStorage |

## 本機預覽

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 部署到 GitHub Pages

Repository → Settings → Pages → Source 選 `Deploy from a branch`，分支選要發布的分支、資料夾選 `/ (root)`。

## 檔案結構

```
index.html          頁面結構
css/style.css       樣式（含深色模式）
js/data.js          所有文字內容：古道資訊、交通路線、題庫、物種、裝備
js/app.js           古道檔案、四大面向、交通動畫、健行場景、護照
js/games.js         四個遊戲
assets/allan/       Allan 角色去背圖（全身、側面、9 種表情）
```

要修改文字內容（例如更新班次、開放狀態），只需要編輯 `js/data.js`。

## 資料說明

內容整理於 2026 年 10 月，來源包括台灣山林悠遊網、林業及自然保育署嘉義分署、阿里山林業鐵路及文化資產管理處、健行筆記與各媒體報導（頁尾有連結）。標示「約」的數字是多方資料整理的概略值；步道開放狀態、公車班次與票價經常調整，出發前請以官方公告為準。
